# rpi-smf

Code for the Student Managed Investment Fund course: a factor-tilted strategy benchmarked to the
Nasdaq-100 (QQQM), adapted from `IPS_FSPTX.pdf`. The whole portfolio is one long-only equity sleeve
(the algorithmic futures sleeve is out of scope). It starts at the benchmark's own weights.
Parameter changes to the IPS are logged in `config/ips.yml: amendments`.

## Setup

```
python3.12 -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/pytest
```

## Weekly workflow

```
rpi-smf import-nq100 --xlsx NQ100.xlsx   # before each rebalance: drop the newest Invesco holdings CSV in data/raw/ first
rpi-smf fetch                   # refresh prices
rpi-smf fit      --date D       # fit the model, print betas
rpi-smf optimize --date D       # solve for target weights (dry run)
rpi-smf trades   --date D       # trades to place (dry run)
rpi-smf check    --date D       # IPS compliance of current holdings
rpi-smf run      --date D       # full rebalance: writes runs/D/, updates the simulated portfolio
rpi-smf perf                    # return, vol, Sharpe, max drawdown, attribution vs QQQM
```

`run` is the whole pipeline (IPS Section 4, steps 1-7). Inputs are taken as of the close
of the business day before `D`; fills are simulated at the close of `D`. Only `run` writes state.

## Inputs (under `data/raw/`, tracked as the audit trail)

| File | What |
|---|---|
| `nq100_constituents.csv` | Generated by `import-nq100` from the Capital IQ export: `ticker,weight,sector,industry_group,industry,sub_industry`. Weights are the fund's `% TNA` from the newest `data/raw/invesco*Holdings*.csv` (GOOG folded into GOOGL; universe = names held); without that file, a market-cap proxy. Source and as-of date: `nq100_constituents.meta.json`. |
| `gics.csv` | `ticker,sub_industry[,sector,industry_group,industry]`, generated alongside. The level used for the 40% cap is `optimizer.gics_level` in `config/ips.yml`. |

Prices (stocks, QQQM, SPY) come from yfinance and the risk-free rate from FRED, cached under `data/cache/`.

## Layout

```
config/ips.yml        every IPS parameter (change only via a dated amendment)
config/factors.yml    the three factors: function, expected sign, parameters
src/rpi_smf/
  data/               nasdaq.py (constituents, weights)  prices.py (yfinance, FRED)  gics.py
  factors.py          factor registry + z-scores              (IPS 4.1)
  model.py            regression, sign rule, MA blend          (IPS 4.2)
  optimize.py         mean-variance QP, lambda calibration     (IPS 4.3)
  compliance.py       limit checks                             (IPS 3, 4.3, 6)
  trades.py           trade list, 1.5pp rule                   (IPS 4 step 6)
  portfolio.py        simulated ledger
  performance.py      metrics + Brinson attribution            (IPS 7)
  journal.py          runs/<date>/ audit trail                 (IPS 4 step 7, 9B)
  pipeline.py cli.py  orchestration
tests/                synthetic data, no network
```

New factor: add a function to `factors.py` decorated with `@register`, then an entry in
`config/factors.yml`. See `docs/methodology.md` for calculations, interpretations and caveats.
