# rpi-smf
Code for the Student Managed Investment Fund course, using a factor-tilted strategy based on FSPTX.

The code in this repository is for managing a factor-tilted strategy based off of FSPTX, supporting the following:
- Pulling returns and financial data on each stock in FSPTX
- Fitting a regression model from user defined factors
- Solving an optimization problem defined from returns predicted by the regression model
- Calculating trades to place

And more, according to the IPS_FSPTX.pdf.
